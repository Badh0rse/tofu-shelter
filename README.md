# TOFU: Earth Apocalypse Survival Shelter (demo)

A shelter-management horror game set in TOFU: Earth Apocalypse. The demo runs to the Long Night on Day 61; the full game unlocks with a code from Ko-fi.

Play: https://badh0rse.github.io/tofu-shelter/

- Game by Buddy (Drunken Norns). Based on TOFU: Threads of Fate Universe.
